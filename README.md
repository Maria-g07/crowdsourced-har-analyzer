## 📝 Περιγραφή Έργου & Σκοπός
Το project αυτό αποτελεί μια full-stack web εφαρμογή που αναπτύχθηκε με στόχο τη συλλογή, διαχείριση και στατιστική ανάλυση πληθοποριστικών (crowdsourced) δεδομένων κίνησης HTTP, τα οποία προέρχονται από αρχεία **HAR (HTTP Archive)** των browsers των χρηστών.

### Πού ωφελεί η εφαρμογή;
Η ανάλυση HAR αρχείων από πολλούς διαφορετικούς υπολογιστές, παρόχους και ιστότοπους επιτρέπει:
*   Την κατανόηση της συμπεριφοράς και της απόδοσης δημοφιλών ιστοτόπων.
*   Την εξαγωγή συμπερασμάτων για την ποιότητα των τηλεπικοινωνιακών υποδομών και των δικτύων (απόδοση, χρόνοι απόκρισης ανά πάροχο/ISP).
*   Τη μελέτη των μηχανισμών κρυφής μνήμης (Caching) και της αποτελεσματικότητάς τους στον Παγκόσμιο Ιστό.

---

## 🔒 Ιδιωτικότητα & Ασφάλεια Δεδομένων (Data Privacy)
Το σύστημα συμμορφώνεται πλήρως με τις αυστηρές προδιαγραφές προστασίας προσωπικών δεδομένων:
*   **Client-side Parsing (JavaScript File API):** Η επεξεργασία του αρχείου HAR γίνεται **τοπικά στον browser του χρήστη** πριν από οποιαδήποτε αποστολή.
*   **Ανωνυμοποίηση:** Αφαιρούνται ακαριαία όλα τα ευαίσθητα δεδομένα (όπως cookies, tokens, form data, query strings). Ο server παραλαμβάνει ένα αυστηρά φιλτραρισμένο JSON που περιέχει μόνο τα απαραίτητα τεχνικά πεδία για την ανάλυση.

## 🏗️ Αρχιτεκτονική & Λειτουργίες Συστήματος
Η εφαρμογή διαχωρίζει τη λειτουργικότητά της με βάση δύο διακριτούς ρόλους χρηστών:

### 1. Απλό προφίλ Χρήστη (Client)
*   **Εγγραφή & Αυθεντικοποίηση:** Σύστημα σύνδεσης και εγγραφής χρηστών.
*   **Upload & Φιλτράρισμα:** Επιλογή αρχείου HAR, τοπική ανωνυμοποίηση και επιλογή είτε για τοπική αποθήκευση του καθαρού αρχείου (`.har`), είτε για ανέβασμα στη βάση δεδομένων.
*   **Διαχείριση Προφίλ:** Αλλαγή στοιχείων λογαριασμού και προβολή βασικών στατιστικών (ημερομηνία τελευταίου upload, πλήθος εγγραφών).
*   **Οπτικοποίηση Heatmap:** Προβολή των τοποθεσιών των IPs των servers πάνω σε διαδραστικό χάρτη με τη χρήση της Leaflet.js.

### 2. Προφίλ Διαχειριστή (Admin Dashboard)
*   **Απεικόνιση Βασικών Πληροφοριών:** Πίνακες με το πλήθος χρηστών, εγγραφών ανά μέθοδο/status code, μοναδικά domains και παρόχους (ISPs).
*   **Ανάλυση Χρόνων Απόκρισης:** Παραμετροποιήσιμα διαγράμματα μέσου χρόνου αναμονής ανά ώρα της ημέρας με πολλαπλά φίλτρα.
*   **Ανάλυση Κεφαλίδων (Cache):** Ποσοστά και directives της Caching συμπεριφοράς (max-stale/min-fresh, public/private/no-cache/no-store).

## 🗄️ Σχεδιασμός Βάσης Δεδομένων (Database Schema)
Η βάση δεδομένων υλοποιήθηκε στο MySQL και περιλαμβάνει τους ακόλουθους πίνακες:
*   **user:** Στοιχεία χρηστών (`username`, `password`, `email`, `last_upload`).
*   **entry:** Κεντρικός πίνακας καταγραφής αντικειμένων κίνησης (`id`, `started_date_time`, `wait`, `server_ip_address`, `isp`, `server_latlng`, `day_request`).
*   **request / response:** Στοιχεία των αιτήσεων και αποκρίσεων.
*   **header_request / header_response:** Καταγραφή των αντίστοιχων HTTP κεφαλίδων (content-type, cache-control, pragma, expires, age, last-modified, host).

## ⚙️ Οδηγίες Εγκατάστασης & Εκτέλεσης (Setup)

### Προαπαιτούμενα
1. Εγκατεστημένο **WampServer** ή **XAMPP**.
2. Ενεργές οι υπηρεσίες Apache και MySQL.

### Βήματα Υλοποίησης
1. **Λήψη του Κώδικα:** Τοποθετήστε τον φάκελο με τα 47 αρχεία στον κατάλογο `www` (Wamp) ή `htdocs` (XAMPP).
2. **Εισαγωγή της Βάσης Δεδομένων:** Ανοίξτε το `http://localhost/phpmyadmin/` και δημιουργήστε μια νέα βάση δεδομένων με όνομα `web` σύμφωνα με τη δομή του Database Schema.
3. **Εκτέλεση της Εφαρμογής:** Ανοίξτε τον browser και πληκτρολογήστε: `http://localhost/το_project_σας/index.php` ή `user_login.php` για τη σελίδα σύνδεσης χρηστών.
