## 📝 Περιγραφή Έργου & Σκοπός
Το project αυτό αποτελεί μια full-stack web εφαρμογή που αναπτύχθηκε με στόχο τη συλλογή, διαχείριση και στατιστική ανάλυση πληθοποριστικών (crowdsourced) δεδομένων κίνησης HTTP, τα οποία προέρχονται από αρχεία **HAR (HTTP Archive)** των browsers των χρηστών.

### Πού ωφελεί η εφαρμογή;
Η ανάλυση HAR αρχείων από πολλούς διαφορετικούς υπολογιστές, παρόχους και ιστότοπους επιτρέπει:
*   Την κατανόηση της συμπεριφοράς και της απόδοσης δημοφιλών ιστοτόπων.
*   Την εξαγωγή συμπερασμάτων για την ποιότητα των τηλεπικοινωνιακών υποδομών και των δικτύων (π.χ. χρόνοι απόκρισης ανά πάροχο/ISP).
*   Τη μελέτη των μηχανισμών κρυφής μνήμης (Caching) και της αποτελεσματικότητάς τους στον Παγκόσμιο Ιστό.

## 🔒 Ιδιωτικότητα & Ασφάλεια Δεδομένων (Data Privacy)
Το σύστημα συμμορφώνεται πλήρως με τις αυστηρές προδιαγραφές προστασίας προσωπικών δεδομένων:
*   **Client-side Parsing (JavaScript File API):** Η επεξεργασία του αρχείου HAR γίνεται **τοπικά στον browser του χρήστη** πριν από οποιαδήποτε αποστολή.
*   **Ανωνυμοποίηση:** Αφαιρούνται ακαριαία όλα τα ευαίσθητα δεδομένα (όπως cookies, tokens, form data, query strings). Ο server παραλαμβάνει ένα αυστηρά φιλτραρισμένο JSON που περιέχει μόνο τα απαραίτητα τεχνικά πεδία για την ανάλυση.

## 🏗️ Αρχιτεκτονική & Λειτουργίες Συστήματος
Η εφαρμογή διαχωρίζει τη λειτουργικότητά της με βάση δύο διακριτούς ρόλους χρηστών:

### 1. Απλό προφίλ Χρήστη (Client)
*   **Εγγραφή & Αυθεντικοποίηση:** Σύστημα σύνδεσης με email και ισχυρό κωδικό πρόσβασης (τουλάχιστον 8 χαρακτήρες με κεφαλαία, αριθμούς και σύμβολα).
*   **Upload & Φιλτράρισμα:** Επιλογή αρχείου HAR, τοπική ανωνυμοποίηση και επιλογή είτε για τοπική αποθήκευση του καθαρού αρχείου (`.har`), είτε για ανέβασμα στη βάση δεδομένων.
*   **Διαχείριση Προφίλ:** Αλλαγή στοιχείων και προβολή βασικών στατιστικών (ημερομηνία τελευταίου upload).
*   **Οπτικοποίηση Heatmap:** Προβολή των τοποθεσιών των IPs των servers (HTML, PHP, ASP, JSP εγγραφές) πάνω σε διαδραστικό χάρτη.

### 2. Προφίλ Διαχειριστή (Admin Dashboard)
*   **Απεικόνιση Βασικών Πληροφοριών:** Πίνακες και γραφήματα με το πλήθος χρηστών, εγγραφών ανά μέθοδο/status code, μοναδικά domains και παρόχους (ISPs).
*   **Ανάλυση Χρόνων Απόκρισης:** Παραμετροποιήσιμα διαγράμματα μέσου χρόνου αναμονής (`timings.wait`) ανά ώρα της ημέρας με πολλαπλά φίλτρα (Content-Type, Ημέρα, HTTP Method, Πάροχος).
*   **Ανάλυση Κεφαλίδων (Cache):** Ιστογράμματα κατανομής TTL και ποσοστά των cacheability/stale-fresh directives.
*   **Οπτικοποίηση Δικτύου:** Χάρτης με δείκτες (markers) των servers και γραμμές που τους συνδέουν με την πόλη προέλευσης του χρήστη, με το πάχος να προσαρμόζεται ανάλογα με το πλήθος των αιτήσεων.

## 🗄️ Σχεδιασμός Βάσης Δεδομένων (Database Schema)
Η βάση δεδομένων υλοποιήθηκε στο MySQL σύμφωνα με το ακόλουθο Σχεσιακό Διάγραμμα:

*   **user:** Αποθηκεύει τα στοιχεία των χρηστών (`username`, `password`, `email`, `last_upload`).
*   **entry:** Η κεντρική οντότητα καταγραφής HTTP αντικειμένων (`id_entry`, `started_date_time`, `wait`, `server_ip_address`, `isp`, `lating`, `server_lating`, `day_request`, `username` ως Foreign Key).
*   **request:** Στοιχεία της HTTP αίτησης (`id_request`, `id_entry` ως Foreign Key, `method`, `url`).
*   **response:** Στοιχεία της HTTP απόκρισης (`id_response`, `id_entry` ως Foreign Key, `status`, `status_text`).
*   **header_request:** Οι καταγεγραμμένες κεφαλίδες της αίτησης (`id`, `id_request`, `id_entry`, `content_type`, `cache_control`, `pragma`, `expires`, `age`, `last_modified`, `host`).
*   **header_response:** Οι καταγεγραμμένες κεφαλίδες της απόκρισης (`id`, `id_response`, `id_entry`, `content_type`, `cache_control`, `pragma`, `expires`, `age`, `last_modified`, `host`).

## 💻 Τεχνολογίες, Γλώσσες & Εργαλεία
Για την υλοποίηση του έργου χρησιμοποιήθηκαν αποκλειστικά **open-source** τεχνολογίες:

*   **Front-end:**
    *   HTML5 / CSS3 (για τη δομή και τη μορφοποίηση - `mystyle.css`)
    *   JavaScript (ES6) / HTML5 File API (για την τοπική επεξεργασία του HAR)
    *   **jQuery (v3.4.1):** Για την ασύγχρονη επικοινωνία (AJAX)
    *   **Chart.js (v2.9.3):** Για τη δημιουργία δυναμικών στατιστικών γραφημάτων
    *   **Leaflet.js:** Για την απεικόνιση των χαρτών και των heatmaps
*   **Back-end:**
    *   **PHP:** Για τη διαχείριση της επιχειρηματικής λογικής (Session management, επεξεργασία δεδομένων, API calls)
*   **Βάση Δεδομένων:**
    *   **MySQL:** Για τη σχεσιακή αποθήκευση των δεδομένων.
*   **Εξωτερικά REST APIs:**
    *   **ipify API:** Για την εύρεση της IP του χρήστη κατά το upload.
    *   **ipinfo.io API:** Για τον αυτόματο γεωεντοπισμό (συντεταγμένες, πόλη, πάροχος/ISP) του χρήστη και του server.
*   **Περιβάλλον Ανάπτυξης:**
    *   **WampServer / XAMPP:** Τοπικός server (Apache, PHP, MySQL) για την εκτέλεση της εφαρμογής.

## ⚙️ Οδηγίες Εγκατάστασης & Εκτέλεσης (Setup)

Ακολουθήστε τα παρακάτω βήματα για να τρέξετε την εφαρμογή τοπικά στον υπολογιστή σας:

### Προαπαιτούμενα
1. Εγκατεστημένο **WampServer** ή **XAMPP** (με εκδόσεις PHP 7.x ή νεότερες).
2. Ένα εργαλείο διαχείρισης βάσεων (π.χ. **phpMyAdmin**).

### Βήματα Υλοποίησης

#### 1. Λήψη του Κώδικα
Κατεβάστε τα αρχεία του project και τοποθετήστε τον φάκελο μέσα στον κατάλογο του τοπικού σας server:
*   Για το WampServer: `C:\wamp64\www\το_project_σας\`
*   Για το XAMPP: `C:\xampp\htdocs\το_project_σας\`

#### 2. Εισαγωγή της Βάσης Δεδομένων
1. Ανοίξτε τον browser και μεταβείτε στο `http://localhost/phpmyadmin/`.
2. Δημιουργήστε μια νέα βάση δεδομένων με όνομα `web`.
3. Επιλέξτε τη βάση `web`, πατήστε στην καρτέλα **Εισαγωγή (Import)**, επιλέξτε το αρχείο `.sql` (export της βάσης) που συνοδεύει το project και πατήστε **Εκτέλεση (Go)**.

#### 3. Εκτέλεση της Εφαρμογής
1. Βεβαιωθείτε ότι οι υπηρεσίες Apache και MySQL είναι ενεργές στο Wamp/XAMPP σας.
2. Ανοίξτε τον browser και πληκτρολογήστε: `http://localhost/το_project_σας/user_login.php` για το προφίλ χρήστη ή `admin_login.php` για το προφίλ διαχειριστή.
